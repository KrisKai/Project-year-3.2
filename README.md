# Smart Home Management System

A full-stack Smart Home solution for monitoring and controlling home devices remotely.

## Overview

This Android app works alongside a Java SpringMVC web platform to provide real-time device control and status monitoring from your smartphone.

## Features

- Real-time device status monitoring
- Remote control of home devices
- RESTful API integration with web backend
- Mobile-friendly Android interface

## Tech Stack

| Layer    | Technology              |
|----------|-------------------------|
| Mobile   | Java, Android SDK       |
| Backend  | Java, Spring MVC        |
| API      | RESTful                 |
| Build    | Gradle                  |

## Getting Started

### Prerequisites

- Android Studio
- Android SDK (API 21+)
- Java 8+

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/KrisKai/Project-year-3.2.git
   ```
2. Open the project in Android Studio
3. Update the API base URL in the configuration to point to your backend server
4. Build and run on an emulator or physical device
